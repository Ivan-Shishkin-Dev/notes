# Lecture 1: The Celebrity Problem

**Definition**
- Person **P** is a **celebrity** if:
	1. Everyone else knows who P is
	2. P does not know anyone else

**Checking if a Person P Is a Celebrity**
- Takes **2n − 2** questions
	- n − 1 other people (everyone minus P)
	- Each of them is involved in 2 questions → "do you know P?" and "does P know you?"
- Checking everyone this way → upper bound of **n · (2n − 2)** questions → O(n²)

**Brute Force Pseudocode**
```
check(P, G):
	for each x in G − {P}:
		if x does not know P: return false
		if P knows x: return false
	return true
```
- This is the brute force algorithm → ask yourself:
	- Did we repeat work?
	- Did we do unnecessary work?

**Better Approach: Elimination**
- Copy the set of people (everyone starts "standing")
- While 2 or more people are standing:
	- Let a, b = two distinct arbitrary people still standing
	- Ask: does a know b?
		- If a knows b → a is **not** a celebrity → remove a
		- If a does not know b → b is **not** a celebrity → remove b
- Every question eliminates exactly one person → takes **n − 1** questions to narrow it down to one candidate
- The last person standing is only a *candidate* → still need to run `check` on them (2n − 2 more questions) → total ≤ 3n − 3 → O(n)

**How Many Celebrities Can a Group Have?**
- So far, we assumed a group has at most one celebrity
- Could a group have zero celebrities? → yes
- Could a group have 2 or more celebrities? → no
	- If A and B were both celebrities → A must know B (everyone knows a celebrity), but A knows no one → contradiction
